# TES 공통 PPT 디자인 가이드

TES IR 자료(2Q26·3Q26)의 정보 구조를 그대로 쓰고, 디자인만 정리한다. 생성기 `scripts/build_template.py`가 아래 규칙을 코드로 고정하고, `examples/수입검사_불량분석.py`가 실제 보고서 예시다.

## 1. 장의 구조 (TES IR과 같음)

1. **머리말**: 섹션 번호(하늘색) + 섹션 이름(네이비), 오른쪽 로고, 아래 가는 선.
2. **제목**: 그 장의 핵심만 짧게 한 줄(26pt 네이비). 예: `월별 불량률 지속 감소`.
3. **본문 패널**: 흰 패널(가는 테두리, 왼쪽 파란 막대가 붙은 패널 제목) 2~3개에 차트·설명·표를 나눠 담는다. 빈 칸을 남기지 않는다.
4. **결론 띠**: 숫자가 있는 장은 아래 네이비 띠에 결론 한 문장.
5. **바닥**: 출처(왼쪽), 쪽번호(오른쪽).

## 2. 글: 제목은 짧게, 본문은 자세히

- 제목에는 핵심만. 수치·근거·조건은 본문 패널에 쓴다.
- 본문 설명은 `무엇이 → 얼마나(수치·비교) → 그래서 무슨 뜻인지`까지 문장으로 쓴다. 항목당 2~4줄.
- 확인하지 못한 원인은 단정하지 않고 "확인이 필요합니다"로 쓴다.
- 한 단어만 다음 줄로 떨어지지 않게 문장을 고친다. `save()`가 넘침·끝줄 한 단어·견본 문구를 찾아 준다.

## 3. IR에서 고친 점

| TES IR | 이 템플릿 |
|---|---|
| 패널 모양·여백이 장마다 다름 | 패널 한 종류(흰 면·가는 테두리·같은 둥근 정도), 바깥 여백 64px·간격 24px 고정 |
| 패널 제목 위치·크기가 제각각 | 패널 제목 20pt 네이비 + 왼쪽 파란 막대, 같은 자리 |
| 차트 색이 여러 가지 | 강조 막대 하나만 TES 블루, 나머지 회색. 격자선·범례 없음, 값 직접 표기 |
| 표 줄무늬·굵은 테두리 | 머리 행만 연파랑, 최신 열만 노랑(IR에서 가져옴), 행 사이 옅은 선 |
| 글자 크기가 장마다 다름 | 머리말 26 / 제목 26 / 패널 제목 20 / 본문 18 / 출처 11pt |
| 사진이 본문에도 들어감 | 사진은 표지·섹션·마무리에만 |

## 5. 그래프·이미지

- 막대 차트는 `chart`(편집 가능)를 먼저 쓴다. 파레토·산점도는 matplotlib PNG를 `two_column` 그림 패널에 넣는다(`figsize=(11, 8)`, `dpi=200`, 글자 24pt 이상).
- 생성 이미지는 표지·섹션·마무리나 개념도에만 쓰고 footer에 `이미지: AI 생성`을 적는다.
