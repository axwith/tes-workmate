# dashboard — 단일 HTML 대시보드 만들기

## 1. 입력 확인
- 쓸 파일마다 행 수, 기간, 열 이름, 빈 값을 한 줄씩 요약한다. 원본은 읽기만 한다.
- 오늘보다 뒤 날짜 행은 집계에서 빼고 뺀 건수를 적는다.

## 2. 집계 규칙
- 수량 열(대수·건수·금액)이 있으면 그 열을 합한다. 행 수로 세지 않는다.
- 평균은 값이 있는 행만으로 내고, 뺀 건수를 화면에 적는다.
- 비율은 분자·분모를 함께 적는다(예: 불량률 = 불량 수 ÷ 검사 수). 비율끼리의 차이는 %p로 쓴다.
- 파레토 = 항목별 합을 많은 순으로 놓은 막대 + 누적 비율 선 + 80% 기준선. 막대 합은 전체 합 카드와 같아야 한다.

## 3. 화면 구성 (기본)
1. 맨 위: 제목, 기간, 핵심 숫자 카드 3~4개
2. 추이(월별 막대 또는 선)
3. 항목별 비교(막대 또는 파레토)
4. 표(차트에 쓴 숫자)
5. 맨 아래: 원자료 파일 이름과 계산 방식 한 줄

## 4. 만들기 규칙
- HTML 파일 하나. `<script src=...>`, 외부 `http` 주소, `fetch(...)`, 웹폰트를 쓰지 않는다. `<meta charset="utf-8">`를 넣는다.
- 값을 먼저 계산한 뒤 차트를 **정적 인라인 SVG**(`<rect>`·`<polyline>`·`<text>`)로 HTML에 직접 쓴다. 브라우저 JavaScript로 차트를 그리지 않는다(스크립트 오류 하나로 화면이 비는 일을 막는다).
- 꼭 필요한 동작(선택 상자 등)만 `<script>`로 넣고, 기본 화면은 정적 SVG로 먼저 보이게 한다. JavaScript 문자열 안에 실제 줄바꿈을 넣지 않는다.
- 막대마다 숫자 라벨. 축 눈금은 1·2·5·10처럼 정수 간격. 음수가 있으면 축에 0선을 그린다.
- 항목 이름은 자르지 않는다. 길면 가로 막대로 그린다. 범례는 차트 위나 오른쪽에 둔다.
- SVG는 `viewBox` + `width:100%`로 패널 안에 전부 보이게 한다(가로 스크롤 금지).
- 저장: 요청한 업무 폴더 또는 `reports/YYYY-MM-DD_주제.html`. 이미 있으면 `-v2`를 붙인 새 이름.

## 5. 끝내기 전 점검
- 저장한 파일을 다시 읽어 차트마다 막대·선 요소와 숫자 라벨이 있는지 확인한다. 빈 차트가 있으면 "완료"라고 하지 않고 고친다.
- 막대 합과 카드 숫자가 같은지 확인한다. 다르면 행 수로 센 것이다.
- 파일 안에 외부 주소가 없는지 확인한다(SVG 네임스페이스 `http://www.w3.org/2000/svg`는 예외).
- 화면 숫자 3개를 골라 원자료에서 찾는 방법과 함께 "대조용 숫자 3개"로 적는다.
- 원인 판정 문장이 없는지 확인한다.
- 저장 위치와 여는 방법(파일을 더블클릭해 브라우저로 열기)을 알려 준다.
