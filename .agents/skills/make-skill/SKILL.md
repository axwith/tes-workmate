# make-skill — 반복 업무를 스킬로

1. 근거 모으기: `memory/candidates.md`의 해당 후보와 근거가 된 `memory/daily/` 기록, 결과 파일을 읽는다.
2. 사용자에게 4칸을 확인한다(이미 기록에 있으면 확인만):
   - 입력 자료(어디서, 어떤 형식)
   - 원하는 결과물(형식, 저장 위치)
   - 꼭 지킬 규칙(계산 방식, 양식, 기준값 — `references/` 참조)
   - 완료 기준(무엇을 대조하면 끝인지)
3. `.agents/skills/<영어-소문자-이름>/SKILL.md`를 만든다. 이름은 영어 kebab-case.
   ```
   ---
   name: <이름>
   description: <언제 쓰는지, 사용자가 실제로 쓰는 말 2~3개 포함>
   ---
   # 제목
   ## 1. 입력 확인
   ## 2. 처리 순서
   ## 3. 결과 저장
   ## 4. 스스로 점검 (완료 기준 대조)
   ```
4. 바로 한 번 실행해 본다. 틀린 곳은 사용자 교정을 받아 SKILL.md를 고친다.
5. `AGENTS.md` 6장 표에 한 줄 추가, 후보 장부 상태를 `승격 → .agents/skills/<이름>`으로 바꾼다.
