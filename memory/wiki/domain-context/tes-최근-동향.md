# 테스 최근 동향 2025~2026

> 공개 자료(공시·회사 누리집·언론)로 만든 참고 위키다. 사내 사정과 다를 수 있고, 사용자가 다르게 말하면 사용자 말이 우선이다. 숫자는 확인일 기준이다.

확인일 2026-11-22

- 범위: 공시(DART·KIND)와 언론 보도로 확인한 공개 정보. 인사·조직은 공시된 대표이사 변경까지만 다룬다.
- 공시 세부(상대방·금액)는 공시 요약 사이트(samara.kr, awakeplus)와 KIND 원문으로 확인했다. 일부 건은 DART 원문을 직접 열지 않았으며 아래 "미확인" 표에 적었다.
- 금액은 부가세 제외 계약금액, 억 원 단위 반올림.
