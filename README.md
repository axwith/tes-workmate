# 테스 workmate — 내 업무 공간 (Codex)

테스 임직원 Codex 실습 교육 3교시 "Codex 활용하기"에서 쓰는 워크스페이스입니다. 설치하면 최근에 쓰던 업무 파일을 이 PC 안에서 읽어 내 업무에 맞게 미리 세팅되고, 대화창에 `@onboard` 한 번으로 실제 업무 중심 셋업을 단계별로 시작합니다.

- 분석은 내 PC의 Codex 안에서만 합니다. 파일을 외부로 보내지 않습니다.
- 최근 업무 파일이 거의 없으면 직무별 가상 예시 자료(연구소·CS·제조·품질·지원)로 세팅됩니다.
- 회사 위키(`memory/wiki/domain-context/`)는 공개 자료로 만든 것이라 사내 사정과 다를 수 있습니다.
- 이름·소속·사내 조직 정보는 파일에서 추정하지 않습니다. 참가자가 직접 입력한 값만 기록합니다.

## 설치

**Windows** — PowerShell을 열고 아래 한 줄을 붙여 넣습니다.

```powershell
irm https://raw.githubusercontent.com/axwith/tes-workmate/main/get.ps1 | iex
```

**Mac** — 터미널을 열고 아래 한 줄을 붙여 넣습니다.

```bash
curl -fsSL https://raw.githubusercontent.com/axwith/tes-workmate/main/install.sh | bash
```

설치 중 기본 검색에 더할 업무 폴더를 묻습니다. 경로를 입력하면 기본 검색(최근 항목·문서·다운로드·OneDrive 같은 동기화 폴더)에 그 폴더를 더해 사전 스캔하고, Enter를 누르면 기본 검색만 합니다. 설치가 끝나면(2~4분) 폴더가 열립니다(Windows `문서\tes-workmate`, Mac `~/Documents/tes-workmate`). 출력에서 선택 경로·발견 파일 수·본문 추출 수를 확인할 수 있습니다.

1. Codex 앱에서 그 폴더를 프로젝트로 엽니다.
2. 대화창에 `@onboard`를 입력해 보냅니다.
3. 사전 스캔 결과와 자료 범위를 고르고, 이름·소속을 직접 입력합니다.
4. 현재 업무·반복 업무·보고 대상·TES 회사/부서 맥락·첫 결과물 종류를 번호로 선택합니다. 3교시 공통 결과물은 본인 업무에 맞는 문서 또는 PPT 초안 1개입니다.
5. 첫 결과물 계획을 확인하고 `1. 계획 승인`을 선택한 뒤 결과물을 생성합니다. PPT는 `@ppt-draft`로 요청합니다(예: `@ppt-draft 방금 읽은 자료로 보고용 PPT 초안 만들어 줘`).

## 쓰는 법

- `@onboard`으로 온보딩 절차를 시작합니다. Mac과 Windows에서 똑같이 씁니다.
- 업무를 시키면 결과와 함께 저장 위치를 알려 줍니다. 틀린 점은 말로 고쳐 주세요.
- "앞으로 항상 ○○" 하고 말하면 바로 규칙(`AGENTS.md` 5장)이 됩니다.
- 일이 끝나면 "정리해 줘"(`wrap`) — 기록이 남고 반복되는 일은 스킬 후보로 쌓입니다.
- 자주 하는 일은 "이 작업을 스킬로 만들어 줘"(`skillers-suda`). 반복 업무 스킬 생성은 선택 사항입니다.
- 자료를 읽고 PPT 초안을 만들 때는 `@ppt-draft`를 사용합니다. 독자·목적·자료·슬라이드 목차를 먼저 계획하고 승인한 뒤 고정 TES 템플릿으로 만듭니다.
- 자료를 더 넣고 싶으면 "최근 파일 더 모아 줘"(`inbox-sort`).
- ChatGPT에서 하던 대화로 내 업무를 더 채우려면 `@chatgpt-import`를 보냅니다. 고른 대화만 읽고, 승인한 것만 저장합니다.

## 교육 뒤에 매일 쓰는 법

설치된 `tes-workmate` 폴더에는 아래 폴더가 있습니다. 파일을 넣을 때와 일을 시킬 때 이 표를 봅니다.

| 폴더 | 넣는 것 | Codex에 이렇게 말합니다 |
|---|---|---|
| `00-inbox` | 새로 받은 파일(메일 첨부, 다운로드). 어디 둘지 모르면 일단 여기 | `인박스 정리해 줘` |
| `10-projects` | 기간이 있는 일(과제·프로젝트). 일마다 폴더 하나 | `10-projects에 ○○ 과제 폴더 만들고 인박스 자료를 옮겨 줘` |
| `20-operations` | 반복 업무(주간·월간 보고, 정기 점검). 업무마다 폴더 하나 | `이번 달 월간 보고 만들어 줘` |
| `30-knowledge` | 배운 것, 정리해 둘 지식 | `오늘 알게 된 내용을 30-knowledge에 정리해 줘` |
| `40-personal` | 개인 메모, 할 일 | `할 일에 ○○ 추가해 줘` |
| `50-resources` | 밖에서 받은 참고 자료(규격서, 매뉴얼) | `50-resources의 규격서 기준으로 맞는지 봐 줘` |
| `90-archive` | 끝난 일 | `끝난 ○○ 과제 폴더를 90-archive로 옮겨 줘` |
| `references` | 기준값, 보고서 양식, 용어집 | `이 양식을 앞으로 보고서 양식으로 써 줘` |
| `reports` | Codex가 만든 결과물. 직접 넣지 않습니다 | `지난주에 만든 보고서 열어 줘` |
| `memory` | Codex의 기억(작업 기록·규칙 후보). 직접 고치지 않습니다 | `지난번에 어떻게 하기로 했지?` |

매일 쓰는 말은 다섯 가지입니다.

| 이럴 때 | 이렇게 말합니다 |
|---|---|
| 일이 끝났을 때 | `정리해 줘` — 한 일과 고친 점이 `memory/daily/`에 남습니다 |
| 고쳐 주고 싶은 점이 있을 때 | `앞으로 항상 …` — `AGENTS.md` 5장 규칙이 됩니다 |
| 같은 일을 또 할 때 | `스킬로 만들어 줘` — 다음부터 한 마디로 같은 순서를 밟습니다 |
| 어제 하던 일을 이어 할 때 | **새 채팅**에서 프로젝트를 `tes-workmate`로 고르고 `지난번에 하던 ○○ 이어서 해 줘` |
| ChatGPT에서 하던 일을 가져올 때 | `@chatgpt-import` — 고른 대화만 읽고, 내 업무·반복 업무·규칙을 뽑아 내가 승인한 것만 저장합니다 |

ChatGPT 대화는 Codex 앱에 로그인한 ChatGPT 계정에서 읽습니다. 읽지 못하면 ChatGPT **설정 → 데이터 제어 → 데이터 내보내기**로 받은 ZIP 파일을 `00-inbox`에 넣고 `ChatGPT 내보내기 파일 넣었어`라고 보냅니다. 개인정보와 고객사 이름은 가린 채로 저장합니다.
