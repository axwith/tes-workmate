# 테스 조직·부서·직무

> 공개 자료로 만든 참고 위키다. 사내 사정과 다를 수 있고, 사용자가 다르게 말하면 사용자 말이 우선이다. 숫자는 확인일 기준이다.

확인일 2026-11-22 · 공개 자료만 사용(회사 누리집·채용 페이지·채용 포털·사업보고서). 공고 내용은 공고 당시 기준이다.

## 핵심 요약
1. 누리집 조직도는 CEO 아래 5개 조직이다. 반도체(Semiconductor), OED(전력반도체·광전자·디스플레이&OLEDoS), R&D, 재무기획(Financial Planning), 경영기획(Management Planning)이다.[^a4]
2. 연구조직은 부설연구소 아래 제품기술연구소·핵심기술연구소 2개와 설계·공정·미래기술·제어·S/W 5개 그룹이다.[^dart] 영업조직은 삼성사업본부·SKH사업본부·OED사업본부다.[^dart]
3. 채용이 가장 많은 직무는 고객사 팹에 상주하는 CS(공정CS·설비CS, PECVD·Dry Cleaning)다. 근무지는 이천·청주·평택·동탄·용인이고 중국 파견 조건이 붙는다.[^jk26q1][^sr0420]
4. 본사·연구소·주 공장은 용인 양지이고, 공장은 용인(양지·원삼)과 화성 향남이다. 중국 시안·우시 법인이 각각 삼성전자·SK하이닉스 중국 CS를 맡는다.[^a5][^dart]
5. 공고에 적힌 도구는 RF 시뮬레이터(HFSS·CST·ADS·COMSOL), 전장 CAD(Solidworks Electrical·EPLAN·OrCAD), AutoCAD, Visual Studio C++·Python·Coverity, ERP, MS-Office·AI 도구, PLC다. SAP·MES·PLM이라는 이름은 확인한 공고에 없다(미확인).[^sr0420][^jk26q1][^lk0908]

## 2. 직무별 하는 일·요구 역량·도구

### 2-1. 연구소: 공정
- 하는 일: 증착·세정 공정 조건 탐색과 장비 특성 분석(공정개발). 신규 기술·장비 구조 탐색과 PoC 검증(미래기술).[^teams] 양산개발 직무는 신공정의 양산성 검증, PECVD 개발 과제의 반복 이슈 대응, 고객 기술 수요 파악을 맡는다.[^jk26q1]
- 요구: 학사 이상, 물리·화학·전자·신소재·반도체공학. 영어 IM 이상, 칩메이커·장비사 경력 우대.[^jk26q1]
- 도구: 미확인.

### 2-2. 연구소: 장비(기구·CAE·RF·전장)
- 기구설계: 반도체 장비 하드웨어·3D 부품/모듈 설계, 부품 선정, BOM·도면·PSM 작성, 원가절감 설계, 조립·시험 기술지원, 초도품 시험.[^jkmech] 고압챔버 기구설계·원삼 근무 기구설계 경력 공고도 있었다.[^catch]
  - 요구: 기계·메카트로닉스·제어계측 전공, 구조해석 경험 우대. CAD 제품명은 미확인.[^jkmech]
- CAE: 구조·열·유동 해석으로 설계 검증.[^teams] FEM 구조해석 공고(석사 이상).[^catch]
- RF 개발(PECVD): 신규 장비 RF 컨셉 설계, RF 네트워크 진단·개선. 학사 이상·경력 5년 이상.[^sr0420]
- RF 회로 설계: RF 필터·매처 회로 설계, 플라즈마 소스 RF 시뮬레이션, 챔버 임피던스 등가회로 분석. 석사 이상·경력 8년 이상. 도구 HFSS·CST·ADS·COMSOL.[^greet]
- 전장 설계: 장비 전원·인터락·시퀀스 설계, 부품·모듈 개발, 성능평가. 도구 Solidworks Electrical·EPLAN·OrCAD.[^sr0420]
- 제어기술: 전원·센서·구동계·RF 제어 시스템, RF Generator·Matching 개발.[^teams]

### 2-3. 연구소: SW
- S/W 개발(CTC): 장비 운영 SW, 물류 이송 스케줄링, 모듈 간 데이터 인터페이스, UI, 로깅.[^sr0420]
- S/W 개발(PMC): 온도·모션 제어, 센서 인터페이스, 실시간 인터락 로직, Device Emulator.[^sr0420]
- 공통 도구: Visual Studio C++ 필수, Python·C#·Java·JavaScript, Coverity 정적 분석 우대.[^sr0420]
- AI 응용 S/W(Edge Computing): 설비 데이터 이상감지·가상계측 모델, 데이터 전처리, Edge 시스템 운영. Python, Linux/Edge Device.[^sr0420]

### 2-4. CS·필드서비스
- 공정CS(PECVD): 신규·이설 장비 공정 셋업, 공정/장비 C/S, CIP 개선 평가, 공정 이슈 원인 분석, 신규 공정 개발.[^jk26q1][^bzpp]
- 설비CS(PECVD): 하드웨어 셋업, 시스템 트러블슈팅, 고객 미팅, CIP 도출·장비 업그레이드 검토, 이력 관리·표준화, 생산성 지표 관리, 해외 사이트 지원. 도구 MS-Office·AI 도구.[^jk26q1]
- 공정CS·설비CS(Dry Cleaning, CLN): CIP 공정 평가, 신규 공정 평가, 설비 이설·셋업·유지보수.[^jk26q1][^sr0420]
- 요구: 학사 이상(일부 전문학사), 물리·화학·전자·전기·기계·신소재. 신입 또는 4~5년 미만. 중국 단기·장기(1~2년) 파견 가능. TSC·HSK 3급 이상 우대.[^jk26q1]
- 설비기술(직무 소개): 설비 상태 점검, 트러블슈팅, 가동률 확보.[^teams]

### 2-5. 제조·조립·테스트
- 제조기술: 장비 조립·검증, CVD·CNC 장비 기능 테스트, 제조 표준화.[^teams]
- 양산 제조/설비(인턴): 양산설비 ATP 테스트, 조립·셋업, 점검·유지보수, 설비 매뉴얼·작업표준 관리. 기계·전기 도면 해독, PLC 기초 우대.[^lk0908]
- 생산능력 연 180 System, 제24기(2025) 생산실적 88대.[^dart]
- SEM Operator 경력 공고가 있었다(세부 미확인).[^catch]

### 2-6. 품질
- 수입·출하 검사, 협력사 품질감사·육성·부적합 관리, ISO9001·14001·45001·SEMI 인증, 고객 Audit·고객불만(VOC) 대응.[^incruit]
- 요구: 이공계 학사, 신입 또는 2년 이하, 영어·중국어 스피킹 IM 이상. 품질기사·통계분석 자격 우대. 도구 미확인.[^incruit]
- 사업보고서에서 확인한 인증은 ISO14001·ISO45001이다. ISO9001은 품질 공고에만 나온다.[^dart][^incruit]

### 2-7. 구매·생산관리·자재
- 구매/자재관리: 부품 조달, 원가 검토, 협력사 관리, 납기·재고 관리.[^teams] 구매/무역 신입(구매관리) 공고가 2026-11-06~11-15에 있었다.[^jkbuy] 공고 원문에 업무 설명은 없다. 고용24 요약에는 발주와 장비·부품 수출이 나오지만 원문은 대조하지 못했다.[^w24]
- 창고관리(계약직): 부품 입고, 자재 이동, 유·무상 파트 포장·전산 출고, 재고실사, 협력사 사급 불출. ERP 경험 우대.[^sr0420]
- 생산관리: 2026년 공고에 직무 태그로만 있고 업무 설명 원문은 미확인이다.[^sr0213]

### 2-8. 경영지원
- 재무관리(공시/회의체): 금감원 정기·주요사항 공시, 거래소 수시공시, 이사회·주총 운영, 정관·사내규정 개정, ESG.[^sr0420]
- 재무/회계: 재무 분석, 자금, 결산, 세무, 내부회계.[^teams]
- 안전관리: 고압가스 안전관리자 선임, POU Scrubber·유틸리티 설비 관리, 화학물질관리법 직무. 도구 AutoCAD.[^sr0420] ESH 체계·위험성 평가·대관.[^teams]
- 영업: 고객 요구 분석, 제안·견적, 수주·납품 관리.[^teams]
- 경영지원: 인사·총무·전산. 임원 비서 공고도 있었다.[^teams][^sr0420]

## 4. 채용 절차·기숙사·복리후생
- 절차: 서류 → AI역량(인성)검사 → 1차 실무면접 → 2차 임원면접 → 채용검진 → 최종합격. 신입 어학 IM 이상, 수습 3개월.[^sr0420]
- 복리후생: 연봉제, 성과급·우리사주, 우리테스인상 시상, 경조 지원·공조회, 자녀 고교·대학 학자금, 종합건강검진, 사내근로복지기금 대출, 법인콘도, 사내식당·체육시설·동호회, 기숙사(본사·화성·청주).[^e2]
- 회사 가치(TES Values): 경영이념 "도전, 창조, 변화". 별도 "인재상" 메뉴는 없다.[^a7]

## 5. 미확인 항목
- 팀 단위 정식 명칭과 인원(공고·누리집에 팀명 없음). 사업보고서의 직원 현황 표는 이번 조회 범위에서 읽지 못했다.
- 5개 연구 그룹의 연구소별 소속 확정
- SAP·MES·PLM 등 사내 업무 시스템 이름(ERP 사용만 확인)
- 기구설계 CAD 제품명, 공정·품질 직무 도구
- 생산관리 직무 설명 원문, 사람인 2026-02·07 공고 상세(이미지 본문이라 텍스트로 못 읽음)
- 잡플래닛·블라인드 등 리뷰 사이트의 부서 단서(이번 조사에서 열지 않음)
