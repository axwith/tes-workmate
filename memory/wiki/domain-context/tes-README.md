# 테스 회사 위키 안내

업무 답변에 회사·제품·업계 맥락이 필요할 때 먼저 보는 문서들이다. 모두 공개 자료(DART 공시, 회사 누리집 hites.co.kr, IR 자료, 언론)로 2026-11-22에 만들었다.

| 문서 | 언제 보나 |
|---|---|
| [회사 개요](tes-회사-개요.md) | 회사 소개·사업장·연혁·조직이 필요할 때 |
| [제품·기술](tes-제품-기술.md) | 장비 이름(Challenger, GPE/CUMAX, KEID, TETRA 등)·공정 위치를 설명할 때 |
| [실적·고객·시장](tes-실적-고객-시장.md) | 실적·수주·고객 비중·경쟁사 맥락이 필요할 때 |
| [최근 동향](tes-최근-동향.md) | 공급계약·신제품·인사 등 최근 소식 |
| 용어집 `references/tes-glossary.md` | 공정·CS·품질·제조·지원 업무 용어 85개 |

- 사내 정보(조직·양식·기준)는 이 위키에 없다. 사용자가 알려 주면 `decisions/`나 `domain-context/`에 새 문서로 남긴다.
- 투자 판단·주가 전망은 하지 않는다. 고객사 이름은 공시에 이름이 없으면 "확인 필요"로 둔다.
