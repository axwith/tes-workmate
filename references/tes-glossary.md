# 반도체 장비 업무 용어집 (테스 직원 업무 기준 분류)

확인일 2026-11-22

- 이 용어집은 반도체 장비 업계에서 일반적으로 쓰는 정의를 쉬운 말로 옮긴 것이다. 테스 사내에서 같은 뜻으로 쓰는지, 사내 약어가 따로 있는지는 확인하지 않았다.
- 쓰는 부서는 업계 일반 관행으로 추정해 적었다(연구=연구소, CS=고객 지원·현장 엔지니어, 제조, 품질, 지원=구매·원가·재고·경영지원).
- 정의 근거: SEMI E10(장비 신뢰성·가동률), SEMI Compilation of Terms, Lam Research·Applied Materials 기술 용어집, ASQ(품질 용어). 출처 목록은 맨 아래.

## 1. 공정 (24)

| 용어 | 풀이 | 쓰는 부서 |
|---|---|---|
| 전공정(FEOL·BEOL 포함) | 웨이퍼 위에 회로를 만드는 단계. 테스 주력 장비가 쓰이는 영역 | 연구, CS |
| 후공정 | 완성된 웨이퍼를 자르고 포장·검사하는 단계 | 연구, 영업 |
| 증착(Deposition) | 웨이퍼 위에 얇은 막을 입히는 공정 | 연구, CS |
| CVD | 기체를 반응시켜 막을 쌓는 화학기상증착 | 연구, CS |
| PECVD | 플라즈마로 반응을 도와 낮은 온도에서 막을 쌓는 CVD. 테스 주력 장비 | 연구, CS, 제조 |
| ALD | 기체를 번갈아 넣어 원자층 단위로 아주 얇고 고르게 쌓는 방식 | 연구 |
| MOCVD | 유기금속 원료로 화합물 반도체 막을 키우는 CVD. LED·GaN에 사용 | 연구 |
| 에피택시(Epi) | 기판 결정 방향을 따라 결정막을 키우는 공정. SiC 전력반도체에 사용 | 연구 |
| 식각(Etch) | 필요 없는 막을 깎아 패턴을 만드는 공정 | 연구, CS |
| 건식 세정·기상 식각(Gas Phase Etch) | 액체 대신 기체로 산화막·잔여물을 없애는 공정 | 연구, CS |
| 하드마스크 | 감광막보다 식각에 잘 버티는 보호막. 깊은 식각 때 패턴을 지킨다 | 연구, CS |
| ACL(비정질 탄소막) | 탄소로 만든 하드마스크 막. PECVD로 쌓고 산소 플라즈마로 지운다 | 연구, CS |
| BSD(뒷면 증착) | 웨이퍼 뒷면에 막을 입혀 휨(warpage)을 줄이는 공정 | 연구, CS |
| 박막봉지(TFE) | 디스플레이 소자를 수분·산소로부터 막으로 감싸는 공정 | 연구 |
| 플라즈마 | 기체에 전력을 걸어 이온·라디칼 상태로 만든 것. 반응을 돕는다 | 연구, CS |
| RF 파워 | 플라즈마를 만드는 고주파 전력. 레시피의 핵심 값 | 연구, CS |
| 레시피 | 온도·압력·가스 유량·시간 등 공정 조건 묶음 | 연구, CS |
| 증착 속도(D/R) | 단위 시간에 쌓이는 막 두께 | 연구, CS |
| 두께 균일도(Uniformity) | 웨이퍼 전체에 막 두께가 얼마나 고른지. 보통 %로 표시 | 연구, CS, 품질 |
| Edge Exclusion | 웨이퍼 가장자리에서 측정·품질 보증에서 빼는 폭(mm) | 연구, CS |
| 스텝 커버리지 | 홈·벽면 같은 단차에 막이 얼마나 고르게 덮이는지 | 연구 |
| 막 스트레스 | 막이 웨이퍼를 당기거나 미는 힘. 휨의 원인 | 연구 |
| 굴절률(RI) | 막 성분·밀도를 가늠하는 광학 측정값 | 연구, CS |
| 파티클 | 웨이퍼에 붙은 미세 이물. 수율을 떨어뜨리는 주요 원인 | 연구, CS, 품질 |

## 2. 장비·CS (22)

| 용어 | 풀이 | 쓰는 부서 |
|---|---|---|
| 챔버 | 공정이 실제로 일어나는 밀폐 공간 | 연구, CS, 제조 |
| 로드락(Load Lock) | 대기와 진공 사이에서 웨이퍼를 주고받는 중간 방 | CS, 제조 |
| EFEM | 웨이퍼 용기(FOUP)에서 장비로 웨이퍼를 옮기는 앞단 모듈 | CS, 제조 |
| FOUP | 웨이퍼 25장을 담아 옮기는 밀폐 용기 | CS |
| 반입(Move-in) | 장비를 고객 팹 안으로 들이는 일 | CS, 영업 |
| 셋업(Set-up) | 반입 뒤 설치·연결·공정 확인까지 마쳐 쓸 수 있게 하는 일. 공급계약 잔금 조건에 자주 쓰인다 | CS, 영업 |
| 훅업(Hook-up) | 장비에 전기·가스·배기·냉각수 배관을 연결하는 일 | CS |
| 인증·퀄(Qual) | 고객이 장비·공정이 기준을 만족하는지 평가해 양산 사용을 승인하는 절차 | 연구, CS, 영업 |
| 데모 장비(Demo) | 고객 평가용으로 먼저 들여 놓는 장비 | 연구, CS, 영업 |
| PM(예방정비) | 고장 전에 정해진 주기로 부품 교체·세정을 하는 정비 | CS |
| BM(사후정비) | 고장이 난 뒤 하는 정비 | CS |
| 알람 | 장비가 이상을 감지해 띄우는 경고. 중대 알람이면 장비가 멈춘다 | CS, 연구 |
| 인터락 | 위험 조건에서 동작을 막는 안전 장치 | CS, 제조 |
| 다운타임 | 장비가 생산에 쓰이지 못한 시간. 계획·비계획으로 나눈다 | CS |
| 업타임(가동률) | 전체 시간 중 장비가 쓸 수 있는 상태였던 비율(SEMI E10) | CS, 영업 |
| MTBF | 고장과 고장 사이 평균 가동 시간. 길수록 신뢰성이 높다 | CS, 품질 |
| MTTR | 고장 한 번을 고치는 데 걸린 평균 시간. 짧을수록 좋다 | CS |
| MWBF | 고장 사이에 처리한 평균 웨이퍼 수 | CS, 품질 |
| FO/FI(Fan-out/Fan-in) | 한 장비 기준으로 웨이퍼 흐름이 여러 쪽으로 나가고 모이는 구성. 회사·고객마다 쓰임이 달라 사내 정의 확인 필요 | CS |
| 수율 | 투입한 웨이퍼·칩 중 양품 비율 | 연구, CS, 품질 |
| 소모품(Consumable) | 정기 교체하는 부품. 샤워헤드·링·O-링 등 | CS, 구매 |
| 워런티 | 출하 후 무상으로 고쳐 주는 보증 기간 | CS, 영업 |

## 3. 품질 (15)

| 용어 | 풀이 | 쓰는 부서 |
|---|---|---|
| 수입검사(IQC) | 협력사에서 들어온 부품을 받기 전에 검사 | 품질, 구매 |
| 공정검사(PQC) | 조립 중간 단계에서 하는 검사 | 품질, 제조 |
| 출하검사(OQC) | 출하 직전 최종 검사 | 품질, 제조 |
| 불량률 | 검사한 수량 중 불량 비율 | 품질 |
| ppm | 100만 개당 불량 개수. 낮은 불량률을 표시할 때 사용 | 품질 |
| SCAR | 협력사에 보내는 시정조치 요구서 | 품질, 구매 |
| CAPA | 원인을 없애는 시정조치와 재발을 막는 예방조치 | 품질 |
| 8D | 문제 해결을 8단계로 정리하는 보고서 양식 | 품질, CS |
| 근본원인분석(RCA) | 겉 증상이 아닌 진짜 원인을 찾는 분석 | 품질, CS, 연구 |
| FA(불량분석) | 고장 부품·제품을 분해·측정해 원인을 밝히는 일 | 품질, 연구 |
| 파레토 | 불량 유형을 많은 순으로 늘어놓아 중점 과제를 고르는 도표 | 품질 |
| 5Why | "왜"를 반복해 원인을 파고드는 방법 | 품질 |
| FMEA | 고장 방식과 영향을 미리 점수화해 위험을 줄이는 분석 | 품질, 연구 |
| 부적합(NCR) | 기준에 맞지 않는 품목과 그 처리 기록 | 품질, 제조 |
| 고객 클레임 | 고객이 제기한 품질 문제 접수 건 | 품질, CS |

## 4. 제조 (12)

| 용어 | 풀이 | 쓰는 부서 |
|---|---|---|
| BOM | 장비 한 대에 들어가는 부품 목록과 수량 | 제조, 구매, 연구 |
| 도면·리비전(Rev.) | 설계 도면과 그 개정 차수 | 연구, 제조 |
| ECN·ECO | 설계 변경 통보·지시. 변경 내용을 관련 부서에 알린다 | 연구, 제조, 품질 |
| 조립 | 모듈·부품을 장비로 꾸미는 작업 | 제조 |
| 모듈 | 챔버·이송부처럼 따로 조립·시험하는 단위 | 제조, 연구 |
| 테스트(장비 시운전) | 출하 전 진공·가스 누설·동작·공정을 점검 | 제조, 품질 |
| 리크 체크 | 진공·가스 라인에서 새는 곳이 있는지 확인 | 제조, CS |
| FAT | 출하 전 공장에서 고객 기준으로 하는 인수 시험 | 제조, 품질 |
| SAT | 고객 현장에 설치한 뒤 하는 인수 시험 | CS |
| 출하 | 완성 장비를 포장해 고객에게 보내는 일 | 제조, 지원 |
| 클린룸 | 먼지·온습도를 관리하는 조립·시험 공간 | 제조 |
| 리드타임 | 주문부터 납품까지 걸리는 기간 | 제조, 구매, 영업 |

| 용어 | 풀이 | 쓰는 부서 |
|---|---|---|
| 구매 발주(PO) | 협력사에 부품을 주문하는 문서 | 구매 |
| 협력사 | 부품·가공을 공급하는 외부 회사 | 구매, 품질 |
| 국산화 | 수입 부품을 국내 공급원으로 바꾸는 일 | 구매, 연구 |
| 장납기 부품 | 주문 후 받기까지 오래 걸려 미리 발주해야 하는 부품 | 구매, 제조 |
| 원가 | 장비 한 대를 만드는 데 든 재료비·인건비·경비 합계 | 원가, 경영지원 |
| 표준원가 | 미리 정한 기준 원가. 실제 원가와 비교해 차이를 본다 | 원가 |
| 재고 | 창고에 있는 부품·반제품·완제품 | 재고·물류, 구매 |

| MRP | BOM과 생산 계획으로 필요한 자재 수량·시점을 계산하는 방식 | 구매, 제조 |
| ERP | 구매·생산·회계를 묶어 관리하는 회사 전산 시스템 | 전 부서 |

| 매출 인식 | 장비 매출을 장부에 올리는 시점. 반입·셋업 조건에 따라 나눈다 | 경영지원, 영업 |
