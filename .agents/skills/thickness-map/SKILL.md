# thickness-map — 두께 분포 HTML 만들기

외부 라이브러리 없이 브라우저에서 바로 열리는 HTML 한 개를 만든다. 이 스킬 폴더의 `template.html`(`.agents/skills/thickness-map/template.html`, 순수 JavaScript)을 복사해 쓴다.

## 1. 읽기
- 자료의 열·단위를 확인하고(README가 있으면 먼저 읽는다) 대상 CSV·엑셀을 읽는다. 열 이름이 다르면 x·y 좌표(mm)와 두께 열을 찾아 맞추고, 무엇을 썼는지 결과에 적는다. 원본은 고치지 않는다.
- 샘플별 전체 점 수, 빈 값(point_id), 두께 최소·최대를 먼저 확인한다.

## 2. 통계
- `AGENTS.md`의 정의(기본 공식, σ=n−1, edge exclusion 규칙)를 따른다.
- 템플릿이 HTML 안에서 같은 정의로 다시 계산해 표로 보여 준다. 따로 계산했다면 두 값이 같은지 비교한다.

## 3. HTML 만들기
1. `template.html`을 해당 업무 폴더 또는 `reports/YYYY-MM-DD_<이름>.html`로 복사한다.
2. 자리표시자를 바꾼다.
   - `__TITLE__` → 그림 제목(샘플·조건·"가상 데이터" 포함)
   - `__DATA__` → `[{"id":"W01","points":[[point_id, x_mm, y_mm, thickness_nm 또는 null], ...]}, ...]`
     CSV 행을 그대로 옮긴다. 빈 값은 `null`. 숫자를 반올림하거나 바꾸지 않는다.
   - `__EDGE__` → edge exclusion mm (기본 0)
   - `__CMIN__`, `__CMAX__` → 색 범위. 자동이면 `null`, 샘플 비교면 같은 숫자로 고정
3. 브라우저는 보안상 HTML에서 옆 CSV 파일을 직접 읽지 못한다. 그래서 데이터를 HTML 안에 넣는다.
4. 템플릿을 쓰지 않고 새로 짤 때도 규칙은 같다: 단일 파일, 외부 `<script src>`·`<link>`·`fetch` 없음.

## 4. 자기 점검 (보고 전에 반드시)
- [ ] HTML 안에 외부 주소가 없다(`<script src>`·`<link>`·`fetch`·`import` 없음). SVG 네임스페이스 문자열 `http://www.w3.org/2000/svg`는 네트워크 호출이 아니므로 괜찮다.
- [ ] HTML에 들어간 점 수가 CSV 행 수와 같다(빈 값 포함).
- [ ] 표의 최대·최소가 CSV의 최대·최소와 같다(edge exclusion 0일 때).
- [ ] 히트맵에서 가장 붉은 곳의 위치가 CSV 최대값 행의 좌표와 맞는다.
- [ ] 색 범위와 edge exclusion 값이 그림 위에 적혀 있다.
- [ ] 모양 한 줄이 반경별 평균과 맞는다. 중심값을 반경 50·100 mm 링 평균과 비교해 "중앙이 두꺼움/얇음/안쪽은 거의 평평"을 고르고, 바깥 두 링(146·148 mm)이 안쪽보다 낮으면 "가장자리 낮음"을 따로 적는다. 차이가 1% 미만이면 "거의 평평"으로 쓴다.
- [ ] "한쪽 치우침"은 같은 링 안에서 한 방향 점들이 반대쪽보다 1% 이상 높을 때만 적는다. 방향은 동서남북 대신 좌표(+x·−y 쪽 등)로 쓴다.

## 5. 보고
저장 위치, 확인 방법(파일을 더블클릭해 브라우저로 연다), 사용 공식·edge exclusion, 계산에 쓴 점 수를 적는다. 모양만 설명하고 원인은 말하지 않는다.
