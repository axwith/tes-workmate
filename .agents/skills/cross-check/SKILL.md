# cross-check — 맞는지 점검하고 확인할 것 고르기

## 1. 대상 정하기
- 사용자가 파일·문장을 주면 그것. 없으면 이 대화에서 방금 만든 결과, 그것도 없으면 `reports/`의 가장 최근 결과 파일. 무엇을 점검했는지 첫 줄에 적는다.
- 근거 자료(원본 엑셀·회의록 등)를 같이 연다. 업무 폴더 `자료/` → `memory/scan/recent-files.csv`의 `copy` 열 → `00-inbox/` 순으로 찾는다.

## 2. 주장·숫자마다 보기
| 항목 | 기준 |
|---|---|
| 자료 근거 | 원본 자료에서 직접 다시 계산·확인되는가 (숫자는 실제로 다시 계산한다) |
| 기준 대조 | `references/`의 기준값·양식과 맞춰 봤는가 |
| 논리 | 원인 → 결과 연결이 무리 없는가, 상관을 인과로 말하지 않았는가 |
| 범위 | 기간·대상이 결론을 내기에 충분한가, 오늘보다 뒤 날짜가 섞이지 않았는가 |
| 숨은 가정 | 말하지 않은 전제가 있는가 |

## 3. 결과
```
점검 대상: [파일명 또는 내용]

맞음 (자료로 확인)
- [항목]: [근거 파일·숫자]

확인 필요 (사람이 현장·담당자에게 확인)
- [항목]: [이유] → 확인 방법: [누구에게, 어떤 자료, 어디서]

주의 (자료 부족·가정에 기댐)
- [항목]: [이유]

믿을 만한 정도: 높음 / 보통 / 낮음
```
- 틀린 숫자를 찾으면 바른 값과 계산 근거를 같이 쓴다. 원본은 고치지 않는다. 결과 파일을 고쳐야 하면 고친 새 파일을 만들지 묻지 않고 만들어 위치를 알린다.
- 길면 `reports/YYYY-MM-DD_<주제>_점검.md`로도 저장한다.
